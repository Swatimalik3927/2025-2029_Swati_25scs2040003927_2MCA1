CHAPTER 4: PROJECT DESCRIPTION
4.1 Introduction
In the current digital era, social media platforms such as Instagram and YouTube have become the primary channels through which brands, creators, and organizations connect with their audiences. The success of any content strategy is no longer measured only by the number of posts published, but by how effectively that content engages its viewers. Metrics such as likes, comments, shares, and impressions provide quantifiable insight into audience behaviour, content quality, and the overall reach of a campaign.
This project, titled “Tracking and Analysis of Social Media Content Engagement Metrics,” was undertaken during a one-month internship as a Data Analytics Intern at Codec Technologies. The objective of the project is to design a systematic approach for collecting engagement data from social media platforms using their official APIs, analyzing the collected data to identify trends and patterns, and visualizing the results through interactive dashboards built in Power BI and Tableau. Based on this analysis, the project also aims to recommend optimal posting times and content strategies that can help improve audience engagement.
The project reflects the growing importance of data-driven decision-making in digital marketing and social media management, and it provided practical, hands-on exposure to data collection, data analytics, and business intelligence tools during the internship period.

4.3 Problem Statement
Organizations and content creators publish large volumes of content on social media platforms such as Instagram and YouTube, but they often lack a structured mechanism to measure and interpret how their audience engages with that content. Engagement data such as likes, comments, shares, and impressions is generated continuously, yet without proper collection and analysis, this data remains underutilized. Content is frequently scheduled based on assumption or convenience rather than actual audience behaviour, resulting in inconsistent reach and engagement.
There is, therefore, a need for a system that can systematically collect engagement metrics from social media APIs, consolidate them into a structured format, analyze them for meaningful patterns, and present the findings through visual dashboards that support data-driven content strategy decisions, including the identification of optimal posting times.
4.4 Project Objectives
To collect content engagement data (likes, comments, shares, and impressions) from Instagram and YouTube using their official APIs.
To clean, structure, and store the collected data for further analysis.
To analyze engagement metrics and identify trends across different content types, formats, and time periods.
To visualize the analyzed data using Power BI and Tableau dashboards for easy interpretation.
To identify the best-performing posting times based on historical engagement patterns.
To recommend content strategies that can help improve overall audience engagement and reach.
4.5 Scope of the Project
The scope of this project is limited to the analysis of publicly available or account-authorized engagement data from Instagram and YouTube through their respective official APIs (Instagram Graph API and YouTube Data API). The project covers the complete pipeline from data collection to visualization and recommendation, including:
Extraction of post/video-level metrics such as likes, comments, shares, views, and impressions.
Time-series analysis of engagement across different days and time slots.
Comparative analysis of engagement across different content categories/formats (e.g., reels, images, videos, carousels).
Dashboard creation in Power BI/Tableau for interactive reporting.
Recommendations on posting schedules and content strategy.
The project does not cover paid advertisement/campaign performance analysis or platforms beyond Instagram and YouTube, and it operates within the rate limits and data-access permissions granted by each platform's API terms of service.

4.7 System Architecture
The system architecture of the project follows a layered data pipeline consisting of four main stages: Data Collection, Data Processing, Data Storage, and Data Visualization.
Data Collection Layer: Engagement data is retrieved from Instagram and YouTube using their official APIs through authenticated API calls.
Data Processing Layer: The raw JSON responses are cleaned, normalized, and transformed into structured tabular data using Python (pandas).
Data Storage Layer: The processed data is stored in CSV files/SQL tables for persistence and further querying.
Data Visualization Layer: Power BI and Tableau connect to the stored data to generate interactive dashboards displaying trends in likes, shares, comments, and impressions.
(Fig. 4.1: Data flows from the Instagram/YouTube APIs → Python-based ETL scripts → structured data store → Power BI/Tableau dashboards → actionable posting-time and content-strategy recommendations.)
4.8 Methodology
Requirement Analysis: Identifying the specific engagement metrics (likes, comments, shares, impressions) relevant to content performance evaluation.
API Integration: Registering developer applications and generating access tokens for the Instagram Graph API and YouTube Data API.
Data Extraction: Writing Python scripts to fetch post/video-level engagement data at scheduled intervals.
Data Cleaning and Transformation: Handling missing values, standardizing timestamps, and organizing data by content type and posting time.
Exploratory Data Analysis: Using pandas and visualization libraries to identify patterns in engagement across time slots and content formats.
Dashboard Development: Building interactive Power BI and Tableau dashboards to visualize KPIs such as engagement rate, reach, and impressions over time.
Insight Generation: Interpreting dashboard results to determine the best-performing posting times and content types.
Recommendation: Compiling actionable recommendations on posting schedules and content strategy based on the analysis.
4.9 Expected Outcomes
A structured dataset of engagement metrics (likes, comments, shares, impressions) collected from Instagram and YouTube.
Interactive Power BI/Tableau dashboards visualizing engagement trends across time and content types.
Identification of the best-performing days and time slots for posting content.
A set of data-backed content strategy recommendations to improve audience engagement.
Practical experience in API integration, data analytics, and business intelligence tool usage gained during the internship.
